각각의 위치를 다 찾아가면서 더한 값을 result 리스트에 넣고 내림차순으로 정렬하고 M보다 작거나 같은 리스트값이 나오면 그 값 출력하고 braek로 가장 가까운 수를 찾아냄

* 효율적인 풀이 *
from itertools import combinations
import sys

input = sys.stdin.readline
N, M = map(int, input().split())
cards = list(map(int, input().split()))

best = 0
for a, b, c in combinations(cards, 3):
    s = a + b + c
    if s == M:          # 정확히 M이면 더 볼 필요 없음
        print(M)
        sys.exit(0)
    if s < M and s > best:
        best = s

print(best)
